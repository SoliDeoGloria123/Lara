🚀 FLUJO DE USO ACTUALIZADO
═════════════════════════════════════════════════════════════════════════════

Ahora tienes 3 formas de usar Lara:

┌─────────────────────────────────────────────────────────────────────────────┐
│ OPCIÓN 1: INPUT INTERACTIVO (RECOMENDADO PARA COMPETENCIAS)                │
└─────────────────────────────────────────────────────────────────────────────┘

# 1. Crear proyecto
lara create mi_backend

# 2. Analizar BD (te pedirá connection string por terminal)
lara get-database

📝 Te preguntará:
   Connection string: [aquí pegas tu cluster]
   mongodb+srv://user:pass@cluster.mongodb.net/DB

# 3. Generar código (futuro)
lara sync-models


┌─────────────────────────────────────────────────────────────────────────────┐
│ OPCIÓN 2: DIRECTO POR PARÁMETRO (MÁS RÁPIDO)                               │
└─────────────────────────────────────────────────────────────────────────────┘

lara get-database -c "mongodb+srv://user:pass@cluster.mongodb.net/DB"

# o formato largo
lara get-database --connection "postgresql://user:pass@localhost:5432/db"


┌─────────────────────────────────────────────────────────────────────────────┐
│ OPCIÓN 3: DESDE ARCHIVO .env (TRADICIONAL)                                 │
└─────────────────────────────────────────────────────────────────────────────┘

# 1. Crear proyecto
lara create mi_backend
cd mi_backend

# 2. Configurar .env
cp .env.example .env
nano .env  # Agregar MONGODB_URL=...

# 3. Analizar BD (lee .env automáticamente)
lara get-database


📊 EJEMPLOS DE CONNECTION STRINGS SOPORTADOS
═════════════════════════════════════════════════════════════════════════════

MongoDB Atlas:
  mongodb+srv://user:pass@cluster0.mongodb.net/EDUSTREAM?retryWrites=true

MongoDB Local:
  mongodb://localhost:27017/mydb

SQL Server (SSMS format - se convierte automáticamente):
  Data Source=localhost\SQLEXPRESS;Initial Catalog=master;User ID=sa;Password=pass;Trust Server Certificate=True

SQL Server (SQLAlchemy format):
  mssql+pyodbc://sa:pass@localhost\SQLEXPRESS/master?driver=ODBC+Driver+17+for+SQL+Server

PostgreSQL:
  postgresql://user:pass@localhost:5432/mydb

MySQL:
  mysql+pymysql://user:pass@localhost:3306/mydb

SQLite:
  sqlite:///./app.db
